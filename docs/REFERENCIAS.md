# Referencias técnicas

- Seguridad por método y habilitación explícita de @PreAuthorize: [Spring Security](https://docs.spring.io/spring-security/reference/servlet/authorization/method-security.html).
- Arquitectura de JWT de un proveedor externo, para la integración SSO pendiente: [Resource Server JWT](https://docs.spring.io/spring-security/reference/servlet/oauth2/resource-server/jwt.html).
- Enlaces de descarga temporales de S3: [AWS S3Presigner](https://docs.aws.amazon.com/java/api/latest/software/amazon/awssdk/services/s3/presigner/S3Presigner.html). Se configura una duración de cinco minutos.
- Renderizado local de clases UML sin proceso externo Graphviz: [PlantUML Smetana](https://plantuml.com/smetana02).
