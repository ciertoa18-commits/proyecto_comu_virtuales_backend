# Diagramas UML

Abrir ComunidadesVirtuales.drawio con diagrams.net para editar las 30 páginas (13 análisis, 13 diseño, 2 generales y 2 BD). Los archivos .puml conservan todos los atributos y relaciones y se pueden abrir con PlantUML en IntelliJ. Las páginas generales de Draw.io son vistas resumidas; los PlantUML generales y relacional incluyen todos los atributos. Las secuencias están en secuencia/CU01.puml hasta CU13.puml.


Se incluyen 43 versiones SVG, una por cada PlantUML, para ver los diagramas sin instalar complementos. Para revisar rápidamente: [diseño de acceso](diseno/CU01.svg), [secuencia de publicaciones](secuencia/CU07.svg), [modelo conceptual](bd/conceptual.svg) y [modelo relacional](bd/relacional.svg).
